GrymoiR 3.0

Un langage de programmation en français courant, pour écrire des applications de gestion fiables : le langage, la base de données et l’application, dans un seul outil.

Un client, conservé, a :
    un nom (texte), unique,
    un solde (nombre).

Le c vaut un nouveau client :
    Le nom vaut « Atelier Dubois ».
    Le solde vaut 120,50.
Conserver le c.
Afficher le solde du client conservé dont le nom est « Atelier Dubois ».

Des nombres décimaux exacts (jamais d’erreur d’arrondi sur une facture), une base intégrée qui se met à jour toute seule quand le programme change, des écrans, des documents imprimés, et des scénarios qui éprouvent un programme avant chaque livraison.

Au premier lancement

Les paquets ne sont pas signés par un certificat payant, et le système le dit une fois :

  • macOS : Contrôle-clic sur GrymoiR dans Applications, « Ouvrir », puis « Ouvrir » encore.
  • Windows : « Informations complémentaires », puis « Exécuter quand même ».
  • Linux : chmod +x GrymoiR-3.0.0-linux-x86_64.AppImage, puis le lancer.

L’atelier s’ouvre sur l’exemple « Amis du Tilleul », une petite association : ses membres, ses cotisations, ses écrans.

Ce qui est nouveau en 3.0

  • Plusieurs postes sur une même application, par le réseau local chiffré, avec des comptes et des conflits refusés au lieu d’être écrasés.
  • Des calculs écrits en C dans une bibliothèque, quand GrymoiR ne suffit pas.
  • Des recherches et des tris jusqu’à trente fois plus rapides.

Les notes de version complètes, avec ce qui n’est pas encore fait.
