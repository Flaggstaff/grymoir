GrymoiR 3.2.0

Un langage de programmation en français courant, pour écrire des applications de gestion fiables : le langage, la base de données et l’application, dans un seul outil.

Un client, conservé, a :
    un nom (texte), unique,
    un solde (nombre).

Le c vaut un nouveau client :
    Le nom vaut « Atelier Dubois ».
    Le solde vaut 120,50.
Conserver le c.
Afficher le solde du client conservé dont le nom est « Atelier Dubois ».

Des nombres décimaux exacts (jamais d’erreur d’arrondi sur une facture), une base intégrée qui se met à jour toute seule quand le programme change, des écrans, des documents imprimés, et des scénarios qui éprouvent un programme avant chaque livraison.

Apprendre, sans rien installer

GrymoiR s’apprend dans ton navigateur. La page Apprendre GrymoiR reprend le guide « Premiers pas » en leçons courtes : tu lis, tu modifies le programme, tu le lances, et tu vois ce qu’il affiche.

Le moteur qui tourne dans la page est le vrai : le même que celui de l’atelier, compilé pour le navigateur. Une erreur y donne le message que GrymoiR donnerait sur ton ordinateur, avec la ligne fautive. Quand une leçon annonce un résultat, la page le cherche dans le tien et te dit si tu l’as obtenu.

Au fil des chapitres, tu construis la gestion d’une petite association : ses membres, leurs cotisations, sa comptabilité en partie double. Onze exercices te font ensuite écrire tes propres programmes, du premier Afficher à ta première base de données.

Pas de compte, pas d’inscription : ton travail et ta progression restent dans ton navigateur, et rien n’est envoyé nulle part. La page tient en un seul fichier ; une fois téléchargée, elle marche aussi hors ligne.

Commencer la première leçon

Les écrans et les documents imprimés se découvrent ensuite dans l’atelier, à télécharger ci-dessous. Navigateurs récents : Firefox, Chrome, Edge ou Safari.

Au premier lancement

Les paquets ne sont pas signés par un certificat payant, et le système le dit une fois :

  • macOS : glisser GrymoiR dans Applications, puis, une fois, dans le Terminal :
    xattr -dr com.apple.quarantine /Applications/GrymoiR.app
    Sans cette commande, macOS dit que GrymoiR « est endommagé » : c’est sa façon de refuser une application téléchargée qui n’est pas signée par Apple. Elle n’est pas abîmée ; la commande retire la marque « téléchargé d’internet », et GrymoiR s’ouvre normalement.
  • Windows : « Informations complémentaires », puis « Exécuter quand même ».
  • Linux : chmod +x GrymoiR-3.2.0-linux-x86_64.AppImage, puis le lancer.

L’atelier s’ouvre sur l’exemple « Amis du Tilleul », une petite association : ses membres, ses cotisations, ses écrans.

Ce qui est nouveau en 3.2

  • Sous Linux, une application fabriquée par l’atelier embarque Qt et la transcription : elle démarre sur une machine où rien n’est installé.
  • Un premier avertissement : un texte collé par suivi de qui perdrait l’espace devant ses deux-points est signalé, avec la forme qui la garde.
  • Au premier lancement d’une application, plus de console de l’atelier derrière la fenêtre du mot de passe.
  • Des corrections de l’analyse : les parties qui s’utilisent elles-mêmes ou s’imbriquent ne font plus tomber l’atelier.

Les notes de version complètes, avec ce qui n’est pas encore fait.
